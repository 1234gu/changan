# 航拍建图任务详情分栏

在「任务中心 → 航拍建图 → 任务详情」进入。页面顶部和视频分析采用相同的信息组织方式：任务身份、触发方式、调度算法、状态、已核验工作单元、实际参与节点、端到端耗时与重试情况。取消、重跑和证据导出沿用现有接口。

| 栏目 | 查看内容 |
|---|---|
| 工作流与执行 | 单机重建或多节点阶段依赖图、照片重叠分组、实际节点时间轴、两轮跨节点重叠、工作单元依赖与状态。可从单元跳到同一次尝试的回执、容器或决策。 |
| 照片与参数 | 任务提交时的 ZIP 名称、大小、照片数、SHA-256；成果预设、分辨率、资源限额、截止时限、选点和重试约束。只有协同模式显示分组、重叠和配准要求。 |
| 容器与镜像 | 应用版本、ODX、镜像摘要、CPU/GPU 访问、各尝试的 Job/Pod、节点、资源申请、观测状态和清理。已清理的历史记录不代表 Pod 当前仍在运行。 |
| 下发与确认 | 分别显示 Job 提交、Pod 首次观测和身份匹配的执行回执。目标节点不冒充实际节点，前两者也不作为实际执行的证据。 |
| 阶段与传输 | 仅汇总成功工作单元上报的实测下载、上传、归档和计算指标；旧版单机无此数据时保留空态。成对的原始阶段事件可查看观测耗时；嵌套阶段不累加。 |
| 调度决策 | 选择某次尝试或工作单元最近一次无可行节点记录，查节点筛选、分值、历史资源快照、约束及原始算法输入。建图分值不解释为已校准预测。 |
| 地图成果 | 已发布的正射预览、配准覆盖、坐标系、分辨率、点云等；按实际清单查看文件及 SHA-256、下载原始产物。无最终成果时不显示下载。 |
| 事件与回放 | 按事件类别及尝试筛选；可跳到第一条、逐条前后浏览或拖动滑条。只读回放不改变当前任务状态，也不触发重跑。 |

支持同一页面持续刷新，选中的栏目和执行尝试不会被轮询重置。任务详情链接可追加 `&tab=flow|input|containers|dispatch|metrics|decision|result|events` 指定初始栏目。标签页支持方向键、Home、End 切换；窄屏横向滑动表格和工作流，不缩小关键字段到不可读。

本轮不改变建图算法、视频详情、K3s 编排、镜像、节点准入或任务 API。不把欠缺的测绘绝对精度、GPU 推理 FPS、文件大小推算为建图传输实测；也不把阶段累计耗时当作加速比。

cd /root/projects/changan-orchestrator/web
npm run build
node --test tests/*.test.{js,mjs}
